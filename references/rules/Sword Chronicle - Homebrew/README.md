# Sword Chronicle — Homebrew

Material autoral de **Aurelia** para o Chronicle System. Tudo aqui é construído sobre as regras canônicas transcritas em [[../Sword Chronicle - Core/README|Sword Chronicle - Core]] e [[../Sword Chronicle - Sorcery/README|Sword Chronicle - Sorcery]].

> **Nota de sistema.** As Lores usam a arquitetura de **2014** — `Lore → Art → Technique` —, não a de 2020. Ver [[../Sword Chronicle - Sorcery/99-divergencias-2014-2020|as divergências]].

## Estrutura

```
Sword Chronicle - Homebrew/
├── Lores/          — sistemas de magia autorais
│   └── Consonancia/
├── Ancestries/     — Ancestry Benefits dos povos de Aurelia
└── Qualities/      — Benefits e Drawbacks autorais
```

Categorias a criar conforme a necessidade: **Houses** (casas de Aurelia com os 7 recursos), **Units** (unidades militares), **Equipment** (armas, armaduras, venenos regionais), **Holdings**.

## Convenções de design

### Lores

Toda Lore segue o checklist dos **Lore Traits** de 2014 ([[../Sword Chronicle - Sorcery/01-lores|referência]]):

| Trait | Pergunta a responder |
|-------|----------------------|
| **Concept** | De onde vem a magia e como é usada? **Se é fácil, por que nem todos fazem? Se é difícil, como alguém descobre que consegue?** |
| **Abilities** | 1 a 3. **Menos abilities = mais fácil dominar.** Uma só deve ser extremamente rara e limitada |
| **Price** | O sacrifício que persuade os poderes ocultos. **"Se dá pra fazer com ação mundana, a mundana é preferível"** |
| **Arts** | Mínimo 3. **Mais poder = mais Arts.** Cada uma com ao menos 1 Ritual e 1 Spell |
| **Resonances** | A matéria do mundo que ancora a magia — e que a **limita logisticamente** |

Cada Lore deve ainda declarar suas manifestações típicas de **Obligations, Taboos, Sorcerer's Aura, Vulnerability e Witchmark** — são os quatro Drawbacks que 2014 exige que cada Lore especialize. **Sem eles a Lore fica incompleta.**

### Calibração

Techniques autorais são calibradas contra as três Arts comuns canônicas:

| Parâmetro | Faixa canônica |
|-----------|----------------|
| **Learning** | 2 semanas Routine (6) → 12 semanas Very Hard (18) |
| **Spell Difficulty** | Challenging (9) a Formidable (12) na base; tabelas escalonadas até Heroic (24) |
| **Ritual Alignment** | Challenging (9) a Formidable (12) |
| **Ritual Invocation** | Challenging (9) a Hard (15) |
| **Ritual Unleashing** | Routine (6) escalonado a Very Hard (18) |
| **Resonances** | 30 prata → 100 ouro |
